# Fee Backcalc

Fee Backcalc は、受け取りたい金額をもとに、サイト手数料を差し引かれても希望額が残る請求金額を逆算するアプリです。必要に応じて消費税も加味し、最終的な請求額を確認できます。

## できること

- 受け取りたい金額を入力して、手数料込みの請求額を逆算する
- 複数サイトの手数料率を登録して、請求額を一覧で比較する
- 税抜きで受け取りたいか、税込みで受け取りたいかを切り替える
- 四捨五入、切り上げ、切り捨てで端数処理を選ぶ

## 想定ユースケース

クラウドソーシングサイトや仲介サービス経由で仕事を受けると、請求額から手数料が差し引かれることがあります。このアプリでは「最終的に 100,000 円受け取りたい」といった希望額から逆算して、各サイトでいくら請求すべきかを確認できます。

## 計算の考え方

受け取りたい税抜金額を `base`、サイト手数料率を `fee_rate`、消費税率を `tax_rate` とすると、請求額は次の式で求めます。

```text
受取希望額(税込) = base * (1 + tax_rate)
請求額 = 受取希望額(税込) / (1 - fee_rate)
手数料額 = 請求額 * fee_rate
```

`税込みで入力` を選んだ場合は、入力した希望額をそのまま税込の受取希望額として扱い、請求額は次の式で求めます。

```text
請求額 = base / (1 - fee_rate)
手数料額 = 請求額 * fee_rate
```

## 入力項目

- 受け取りたい金額: 最終的に手元へ残したい金額
- 受け取りたい金額の入力形式: 希望額が税抜きか税込みか
- 消費税率: 請求時に加算する税率
- 端数処理: 四捨五入、切り上げ、切り捨て
- 依頼サイト名 / 手数料率: サイトごとの比較条件

## 出力項目

- 依頼サイト
- 手数料率
- 差し引かれる手数料
- 請求額
